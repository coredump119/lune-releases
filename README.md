# LUNE · downloads

Midjourney 提示词 / 效果图 / `--p` 值的本地管理器，by NullPointer。免费使用，不开源。

- **macOS**（Intel + Apple 芯片通用）：[LUNE-mac.dmg](https://nullpointer-doe.pages.dev/dl/LUNE-mac.dmg)（[GitHub 直链](https://github.com/coredump119/lune-releases/releases/latest/download/LUNE-mac.dmg)） — 暂未签名。第一次打开若提示「无法验证」：系统设置 → 隐私与安全性 → 底部「仍要打开」，只需一次（或终端 `xattr -dr com.apple.quarantine /Applications/LUNE.app`）
- **Windows**：[LUNE-windows-setup.exe](https://nullpointer-doe.pages.dev/dl/LUNE-windows-setup.exe)（[GitHub 直链](https://github.com/coredump119/lune-releases/releases/latest/download/LUNE-windows-setup.exe)） — 出现 SmartScreen 时点「更多信息 → 仍要运行」
- **网页版**：https://lune-cv8.pages.dev — 数据只在当前浏览器里，长期使用建议桌面版
